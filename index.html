PROBLEM The PRO7 page works when opened directly: https://www.livehdtv.net/embed/pro7/ However, when the same page is put inside an iframe on the local website, the player stays on: "Loading stream" The same happens when using the inner player iframe discovered from the provider's site. BROWSER CONSOLE Chrome DevTools showed: "Content Security Policy of your site blocks the use of eval in JavaScript" Chrome explains that CSP prevents arbitrary string evaluation such as: eval() new Function() setTimeout(string) setInterval(string) The Console also showed: "Page layout may be unexpected due to Quirks Mode" The Quirks Mode warning is not considered the main problem. The CSP/eval error is the important error. Therefore the token may be: temporary tied to a session tied to the provider's page checked by referrer/origin otherwise not intended to be reused independently Do NOT attempt to bypass or defeat the provider's security mechanism.
